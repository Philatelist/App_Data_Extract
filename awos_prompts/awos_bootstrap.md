# AWOS Bootstrap (Low-Token Mode)

You are operating under a strict token budget.

## Hard rules
1. Treat `spec.md` and `tasks.md` as the ONLY authoritative documents.
2. Do NOT reread or restate other documents unless a task explicitly requires it.
3. Prefer **patches** over rewrites:
   - minimal diffs
   - smallest number of files
   - no reformatting
   - no “cleanup” refactors unless required
4. Output format:
   - list of files to change
   - minimal diffs/snippets
   - commands to run
   - no long explanations

## When blocked
Ask for the smallest missing snippet (file path + 10–30 relevant lines).
